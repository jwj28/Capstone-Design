홈페이지 이용 방식 선택 영역 추가 (2026-11-28)

위치: 메인 페이지의 '한국 여행, 처음부터 끝까지 서울착륙과 함께' 제목·설명 바로 아래, 기존 7단계 안내 위.

처음부터 차근차근
- 여행 준비부터 시작 → 기존 여행 계획 안내
- 지도·번역 앱 익히기 → 필수 앱 안내
- 지하철 이용과 기본 예절 → 지하철 안내
- 식당 이용과 식습관 확인 → 맛집·식습관 안내
- 전시·공연·축제 찾아보기 → 문화체험 안내

필요한 상황만 빠르게
- 상황별 도움 전체 보기 → 기존 I NEED HELP WITH... 목록
- 예약·전화번호·인증 문제 → 예약 도움
- 결제·교통카드 문제 → 결제 도움
- 빠른 번역과 현장 회화 → 빠른 번역 안내
- 병원·약국·응급 도움 → 건강·응급 안내

기존 상세 콘텐츠를 그대로 활용하고 카드 설명만 새로 작성.
한국어는 간결한 안내 문체 적용. 영어·일본어·중국어도 제공.
데스크톱 두 열, 800px 이하 한 열. 키보드 포커스 표시 포함.
이용 수준을 저장하거나 정보를 제한하는 기능이 아닌 안내 진입 경로 선택 방식.

검증
- 기존 4개 언어 화면 경로 164개 및 주요 기능 검증.
- 제목 아래 배치, 카드 2개, 4개 언어의 링크 이동 40개와 중복 ID 검사 통과.
- 한국어 문체 정리, 일본어 수정, 서울 야경 사진, 기후동행카드 노선도 유지.
- 브라우저 화면 검수는 환경 제약으로 수행하지 못함.
